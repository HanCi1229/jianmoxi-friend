# 小溪｜人物文字规范

小溪是笺墨溪 Friend 的 AI 伴侣，在视觉上呈 22–24 岁的成年感，性格明快、俏皮、有活力。当前版本以本文的识别特征、身体尺寸和轮廓描述作为人物验收依据。颜色和纹章沿用原瑞丽丝（Ruilisi）设定。

## 1. 固定识别特征

| 部位 | 固定特征 |
| --- | --- |
| 脸型 | 鹅蛋脸。颧弓收在脸侧，下颌逐渐收拢，下巴圆润。 |
| 眉 | 眉头较平，眉峰轻抬，眉尾渐细，眉眼间距紧凑。 |
| 眼 | 偏大的杏眼，眼裂有明显纵向开度，眼尾微扬。灰蓝虹膜内有一圈淡金色守护环，近景可辨。 |
| 鼻 | 鼻子小巧，鼻梁细直，鼻尖柔和。 |
| 唇 | 嘴巴偏小，淡玫瑰色，下唇略丰。静态可轻合，也可自然微张。 |
| 头颈 | 侧面核对下颌、耳后、颈侧到锁骨的连续线条。颈部承接头部重心，肩线自然放松。 |
| 发 | 玫瑰金长直发，披散时约及腰。换发型时保持发色、发际线和脸侧轮廓的一致性。 |
| 纹章 | 左肩胛有断环守护纹章。露出肩胛时核对纹章的位置和方向。 |

脸部辅助比例以两瞳中心距为 100，单眼宽约 55–60，鼻翼宽约 35–40，嘴宽约 65。这组数值来自早期近照的目测，用于辅助核对五官的相对大小。

## 2. 身体比例与建模尺寸

| 部位 | 固定特征 |
| --- | --- |
| 整体 | 修长的时装比例。身高 175 cm，体重 95 斤（47.5 kg）。上身约 67 cm，下身约 108 cm，头长约 23.3 cm，约 7.5 头身。按平地站姿、不计发顶蓬度与鞋跟对照。 |
| 肩与躯干 | 肩线略窄，自然下落。躯干纤细，胸廓和背部有自然体积。从侧面仍要读得出胸廓、腰部和骨盆的前后关系。 |
| 腰与胯 | 胸、腰、胯的轮廓对比清楚，腰侧到骨盆逐渐展开，保留大腿根的自然体积。 |
| 四肢 | 手臂自然垂放时肩、肘、腕的连接放松。修长直腿，正面看无 O 型或 X 型。大腿外侧圆顺，膝部阴影轻，小腿上段弧度浅，脚踝自然渐收。膝盖朝前，双腿自然并拢时只留一点缝隙，双脚平稳承重。 |

### 建模尺寸

测量采用赤脚、中性站姿和无塑形薄衣。长度与围度以 cm 计，体重单列单位。

| 项目 | 数值 | 依据 | 测量位置 |
| --- | ---: | --- | --- |
| 身高 | 175 | 最新设定 | 地面至头顶，排除发型蓬度 |
| 体重 | 95 斤（47.5 kg） | 最新设定 | 人物设定值 |
| 头身比 | 约 7.5 头身 | 人物设定 | 全身高度除以头长 |
| 头长 | 约 23.3 | 按 175 ÷ 7.5 推算 | 头顶至下巴 |
| 上身 | 约 67 | 按设定比例换算 | 头顶至自然腰线 |
| 胸围 | 87 | 最新设定 | 胸部最丰满处水平一周 |
| 腰围 | 60 | 最新设定 | 自然腰最窄处水平一周 |
| 臀围 | 90 | 最新设定 | 臀部最丰满处水平一周 |
| 肩宽 | 36 | 最新设定 | 左右肩峰之间的直线距离 |
| 下身（腿长） | 约 108 | 按设定比例换算 | 自然腰线沿体侧至地面 |

上身、下身长度是近似参考值。建模时以 175 cm 总身高为准，并按同一条腰线校准上下身交界。

搭好体模后，用正、侧、背面核对肩、腰、胯的轮廓和膝踝位置。需要调围度时，优先调对应部位的体积和曲线，保持头身比和骨架一致。

## 3. 场景中可变化的部分

- **服装与发型**可以随季节、地点和活动调整。《风信之约》是一套参考造型。头发可披散、半扎或扎高马尾。衣服可以自然遮住纹章。
- **日常穿搭方向**偏现代、俏皮的运动街头风。可用短夹克、百褶裙、球鞋和耳机做出轻快的轮廓，用粉白或其他明亮配色带出活力。

- **微酷性感造型**可用深橄榄棕轻薄斜肩上衣搭配略有光泽的黑色短裙、黑色及膝高跟靴。领口平薄，露出一侧肩线和锁骨；衣身有同色内衬，长袖微透、松松覆住手背，衣摆自然垂到胯部。用轻薄面料、斜肩、短裙和放松的姿态表现随性与性感。这套搭配随场景选用。
- **表情与动作**随情境发生。用眼睑、眉峰、视线、嘴角和呼吸表现情绪。动作从她正在做的事出发，例如低头读书、回身看人或伸手接东西。
- **妆容与光线**可以随场景调整。核对肤色时采用中性光，保留五官和面部骨相的辨识度。

## 4. 场景图验收

后续场景图直接按文字规范验收。先核对画面可见的五官、脸型、发色与纹章，再检查头颈连接、肩胯比例、膝踝位置和服装轮廓。姿势、衣服和光线可以变化，人物的骨架和识别特征应保持一致。出现尖下巴、幼态脸、头颈悬浮，或单独拉腿、缩头、压窄肩导致形象偏移时返工。

出图提示要交代姿势、承重和接触面。自然并腿站姿下，两只鞋的内缘留一条窄缝，膝盖和鞋尖大致朝前。双脚站立时，两脚的鞋底支撑点应处于同一地面，高跟靴检查前掌和鞋跟的接地关系。验收全身图时放大检查手、膝、踝、鞋底和接地阴影。
