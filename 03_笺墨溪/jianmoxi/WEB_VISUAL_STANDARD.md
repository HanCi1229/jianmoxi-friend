# 笺墨溪网页版视觉标准

2026-11-08。适用于 `/web/index.html`，样式限定桌面宽度大于 680px。

## 参考与取舍

- Ant Design 字体：https://ant.design/docs/spec/font-cn/ 。使用系统界面字体和克制的字号层级。
- Ant Design 对齐：https://ant.design/docs/spec/alignment-cn/ 。标题、搜索、列表采用共同左起点。
- Linear：https://linear.app/now/behind-the-latest-design-refresh 。降低导航视觉重量，固定顶栏和操作位置。
- Awwwards：https://www.awwwards.com/websites/minimal/ 。参考留白和内容优先的排版。

## 统一尺寸

- 主导航宽 216px；681–1080px 窗口宽 176px。历史侧栏分别 248px / 208px。
- 品牌、历史标题、内容顶栏统一 64px 高；两侧新建按钮顶部均为 88px，高 40px。
- 内容边距 36px，窄窗口 24px；使用 8px 间距节奏。
- 操作界面采用系统无衬线字体；品牌、文学摘句、文章正文保留文学字体。
- 页标题 26px，列表标题 17–18px，正文 14–15px，辅助信息 12–13px。
- 搜索框高 42px、圆角 8px；导航高 44px；卡片圆角 10px；输入区圆角 12px。
- 保留暖白纸色、鼠尾草绿与原有可选纸色。用细边框和轻阴影区分层级。
- 对话的主导航选中项由实际打开状态决定，不使用背景页面状态。
- 对话区独立滚动，背景页面不滚动。手机沿用现有布局。

## 后续维护

桌面视觉规则统一维护在 `dist/web/desktop.css` 最后的 Desktop visual system 区域。避免在共享移动端样式中添加桌面例外。新增控件优先复用已有尺寸，不为单页独立放大字号或增加另一套圆角。

## 网页灵感列表

桌面灵感改为纵向单列卡片，内容区域最大 960px。卡片左侧为 144px 小图，右侧为 18px 文学摘句和出处；窄窗口缩至 112px 小图。取消横滑、吸附和固定卡片高度，长摘句自然展开，无配图时正文占满。解读、讨论、收藏统一置于底部右侧。手机保留原布局。
