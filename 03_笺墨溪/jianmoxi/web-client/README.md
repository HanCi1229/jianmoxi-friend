# 笺墨溪网页端

`web-client/` 是桌面和移动浏览器的独立前端，沿用产品的纸本文艺风格与五栏导航：灵感、对话、阅读、文章、我的。页面使用原生 HTML、CSS、JavaScript，不依赖打包器、第三方 CDN 或新后端接口。

## 已接入功能

- 登录、登出、云端状态读取与版本化保存；遇到并发修改时保留本地未同步副本供下载。
- 灵感卡片、语录解读、灵感偏好、天气与城市问候。
- 小溪多轮对话、历史会话与停止回复。
- 书库检索、章节阅读、收藏、选区复制、摘录增删和选段解读。
- 文章新建、编辑、搜索、完成状态、回收站、恢复、导出、每日目标和写作统计。
- 小溪名字、人设、回答风格和记忆管理。

## API 与托管

前端只访问当前网页来源下的 `/api/`，由 `api.js` 统一处理登录态、错误和并发冲突。`home-api.js` 和 `reading-api.js` 提供首页及阅读功能的接口封装。所有脚本由 `index.html` 按依赖顺序加载。

已于 2026-11-08（北京时间）发布到 https://49.234.43.25/web-client/ 。Flask 以白名单提供本目录的首页和六个 JS/CSS 文件，继续使用同源 `/api/`、访问密码和云端数据。生产根入口与 `dist/` 保留原版。

发布使用线上最新 `cloud_app.py` 增加静态路由，避免本地旧后端覆盖线上改动。发布前的代码及一致性数据库快照保存于 `/var/lib/xingzou/backups/before-web-20261107-175035`（目录时间为 UTC）。服务健康检查通过；七个前端文件的公开 HTTPS 内容均与本地 SHA-256 一致，未登录状态接口返回 401，非白名单文件返回 404。实际浏览器已成功登录，后续产品验收由用户完成。

灵感页面默认读取已缓存内容；“换一组”只改变读取游标，不请求模型。天气只在用户搜索并选择城市后查询。首页不自动生成 AI 问候；选择心情时才请求问候，写作、阅读和对话 AI 也只在用户主动操作时调用现有服务。

## 设计约束

- 灵感卡片保持窄幅、纵向修长，只横向滑动；详情聚焦语录解读。
- 阅读搜索覆盖作品、作者与正文，阅读选区工具优先出现在选段下方。
- 写作使用原生 textarea，保留键盘输入与剪贴板能力。
- 宽屏显示左侧导航；窄屏固定显示底部五栏导航。
- 同步的 `sources/` 内容保持只读；网页端目录独立于 `dist/`，凭据与数据库不属于公开网页资源。
