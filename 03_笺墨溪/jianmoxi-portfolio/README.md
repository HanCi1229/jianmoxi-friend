# 笺墨溪｜AI 阅读与创作应用

[在线作品集](https://hanci1229.github.io/jianmoxi-portfolio/) · [HTML 文件](./index.html)

笺墨溪是一款将文学阅读、灵感收藏、写作与 AI 搭子连接起来的个人产品。它关注的是，读者读到的文字能否留住出处，在下一次构思和写作时找得到、用得上。

## 项目介绍

**代表场景**　用户可以对 AI 搭子说“从我指定的书里，找几段关于日常的文字，做成灵感卡”。系统先检索书库原文，模型根据主题挑选摘句并写解读。服务端核对摘句是否确实存在于检索结果，按书库记录填写作者、作品及章节，并在保存前复核当前原文。通过核验的卡片进入灵感列表，保留来源。

**产品决策**　让模型处理主题理解、文学筛选和解读，让程序处理原文核验、出处归属与保存。摘录和 AI 原创是两个明确的模式。原文不足或发生变化时，流程提示重试，避免把临时生成的文字写成原书摘录。

**交付形态**　项目已有私有云端 Web 版本与 Android 安装包。作品集用独立的示例文本展示同一条产品链路，并提供原文一致、改写被拦截两种可点按的演示。
