前端布局灵感板

前端设计层面 · 六种布局范式

只谈版式、栅格、留白、字号层级与视觉语言，不谈交互逻辑与按钮去留。参考：Cursor、Linear、Claude / Anthropic、Perplexity、Notion、v0、Lovable、Replit，以及 2026 AI Minimalism 与编辑式反向路线。每张 960×540，默认 1:1。

Type 字号阶梯

固定阶梯 12 / 14 / 16 / 20 / 28 / 40，不出现随意中间值；正文 19px / 1.6–2.1；标题左对齐、字距收紧；最多两种字重；衬线只用于大标题。

Space 间距

组件内 8 / 16 / 24 / 32 / 48，区块间 60 / 80 / 100，安全边距 96；留白是版式主体，不是剩余空间。

Measure 栏宽

长文 640／图文组合 960／宽版 1280；每行控制在 65ch 内；正文栏不随窗口拉满。

Color 表面

暖白 #F7F6F3、白 #FFFFFF、细线 1px #EAEAEA、文字 #111111 / #787774；单一强调色，只用在链接与一处高亮。

Surface 分层

只做三层：背景 / 抬起的卡 / 分隔线。靠底色一档之差和留白分层，不堆阴影、不叠卡片（嵌套 ≤ 2 层）。

Motion 动效

150–300ms、只动 transform 与 opacity、一个动效概念、尊重 prefers-reduced-motion；无无限循环装饰动画。

01 产品即首屏 · 无顶部横栏

Cursor / Claude / Perplexity
内容从 96px 安全边距起
唯一浮层：底部输入 480×56
顶部 0 横栏 · 0 导航
版式：整屏就是产品本体，没有一条贯穿的导航栏；控件浮在角落或底部，不占顶部通栏。视觉：暗底 + 一处强调色，层级靠字号差与留白，不靠边框。
对应我们的首页：顶栏已去掉，剩下的问题只是「归来卡放哪、输入条多宽」。

02 中央窄栏 + 巨量留白

AI Minimalism · Claude / OpenAI / iA Writer
640px 阅读栏
左侧留白 160
右侧留白 160
无侧栏 · 无工具栏 · 无卡片
版式：正文栏 640–720px 居中，四周留白 ≥ 96px，全屏只有文字。视觉：暖白底、近黑字、灰次级字，标题左对齐、两种字重；连工具栏都可以收起。
对应沉浸模式：我们现稿是 800px 栏，可对照 640 的「更窄更静」一档。

03 左主右辅 · 细线分栏

Cursor / Replit / 编辑器类
主区 70% = 672
辅区 30% = 288
辅区只放一块批注卡
1px 细线分区，不用阴影
版式：70/30 分栏，分隔靠 1px 细线与辅区一档底色差（#FFF → #F7F6F3），不靠卡片投影。视觉：主区永远完整，浮层不压正文；辅区元素少且尺寸统一。
对应陪伴模式：现稿 1008 / 432 正是这个比例，差别只在辅区的密度。

04 不对称编辑式 40 / 60

文字 40%
你停在
那句话里
场景 / 视觉 60%
暖白 + 衬线大标题 + 单一强调色，零渐变零发光
版式：左右不等宽（40/60），打破「三张等宽卡」的模板感；文字左对齐，大标题用衬线，行距松。视觉：奶油底、近黑字、一处强调色，情绪靠排版而非特效。
对应首页归来：归来卡可以是文字块，场景是留白里的另一半，不必做成浮层卡片。

05 输入框即首屏

Perplexity / Lovable / v0
主视觉 600×72 · 唯一主角
下面只放 3–4 条示例，不加卡片
首屏其余区域全部留白
版式：一个真实输入框就是全部主视觉，居中、宽 600 左右；下方 3–4 条示例文字，不做卡片墙。视觉：每屏只有一个主行动点，其余按钮退成文字或线框。
对应常驻聊天框：现稿 960×72 在底部；这一版是把它抬成画面中心的另一种排版可能。

06 三栏层级 · 靠底色不靠边框

Linear / Cody / 工作台类
导航 200
主内容 560
上下文 200
三档底色分层：白 / 暖白 / 白，不加第三条竖线
版式：窄导航 200 + 主内容 + 窄上下文 200，主区留白最大。视觉：层级靠两档底色差和栏宽差，边框只出现 1px；卡片不嵌套。
对应阅读：现稿是 320 / 1120 两栏；三栏是另一种信息密度，可作对照。

A · 暗色科技（Linear / Cursor）

暗底为设计起点、单一霓虹强调、等宽字体点缀、bento 尺寸表达层级。工具感强，长时间读文字略费眼。

B · 暖白编辑（Anthropic / Notion / Claude）

奶油底、衬线标题、巨量留白、几乎无装饰。2026 被视作反模板路线，更贴长文与陪伴气质。
两条只是待选，不定，等你挑。

反模板清单（Anti-slop）：紫色渐变＋暗 mesh 背景、三张等宽功能卡、默认 Inter、全站发光与无限漂浮、卡片嵌套超过两层、每屏多个同等强度按钮、装饰性视差堆叠加。这些是「一眼看出是 AI 做的」主要来源。
